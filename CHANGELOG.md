# Changelog

## 1.0.0 – 2026-11-21

First public release.

- Real 3D extrusion of any image with an alpha channel.
- Sides textured with the colour of the image edges, or a solid colour.
- Built-in lighting (ambient + key light) with adjustable intensity.
- Manual X / Y / Z rotation.
- Auto Rotate with a constant speed in turns per second.
- Bevel, alpha threshold and texture alignment controls.
- Custom icon for the Effects Library.
